# Declared clusters (`clusters/`)

One flat file per declared cluster, named `<cluster>.yaml`, holding that cluster's identity: `key: value` lines only (one scalar per line, `#` comments allowed, no nesting), with keys from the design's table (`cluster`, `environment`, `role`, `maturity`, `sourceRef`, `tailnetNode`, `storageClass`, `domain`, `harborRole`, `harborCentral`, `gcpProject`, `gcpRegion`, `pullerSchedule`). nordri's `identity.sh` reads each file over the environment's defaults (`identity/defaults-<environment>.yaml`) and under any `NORDRI_IDENTITY_<KEY>` environment variables. A cluster with no file here is treated as a lab. GKE clusters must be declared, because nothing else tells them apart from a lab. Set `tailnetNode: stamped` on a test cluster that needs the tailnet: the node name becomes `<cluster>-<yyyymmdd-HHMM>` at bootstrap.
